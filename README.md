# NovaCart - Mini E-Commerce Application

Professional college mini e-commerce website with 20 sample products.

## Technologies
HTML, CSS, JavaScript, Axios, JSON Server.

## Run
1. Open this Ecommerce_project folder in VS Code.
2. Run `npm install`.
3. Run `npm start`.
4. Keep JSON Server running.
5. Right-click `views/index.html` and choose Open with Live Server.

## Categories
Electronics, Fashion, Home, Beauty.

## API
/products, /users, /orders

Login and checkout are demonstration features for a college project; do not use real passwords or payment details.
